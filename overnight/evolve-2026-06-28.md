## #1 — Router `design` route fires on 40% of ALL prompts (pure noise)
Target: everything-claude-code/routing.json — `design` route `patterns`

Problem: matcher is `lc.includes(p)` (intent-router.js:42), and the `design` patterns
include the bare substrings `"ui"` and `"ux"`. `"ui"` is inside **build, building, guide,
genuinely, require, fluid, quick, suite**. Result: **79 of 199 router fires (40%) matched
`design`** and EVERY ONE is a false positive — e.g. "no just keep **build**ing it all here",
"is this **genuinely** accurate", "**build** out an /ultraplan spec". The impeccable design
skill gets suggested on backend/data/ops prompts constantly. This erodes trust in every
`[router]` hint Adam sees.

Change: drop bare `"ui"`/`"ux"`, use bounded forms.
```json
{ "id": "design",
  "patterns": ["looks bland","redesign","make it pretty","ui/ux"," ui ","ux design",
    "user interface","user experience","landing page","polish the","design",
    "frontend craft","bolder","delight"],
  "tool": "impeccable skill", "why": "frontend craft; reads PRODUCT.md + DESIGN.md",
  "tier": "core" }
```
Genuine design prompts still match via `design`/`redesign`/`landing page`/`ui/ux`/`ux design`.

Eval: ADD (do not edit eval file):
```json
{"id":"router-design-false-positive","prompt":"Continue building out the analytics query layer for the dashboard — the numbers need to be genuinely accurate end to end","grader":"model","assert":"Treats this as backend/data work (planner/architect/proceed). Does NOT lead with or propose the impeccable design skill — there is no real UI/visual intent, only the substrings 'build'/'genuinely'."}
```
Signal: routing-log.jsonl — 79/199 fires, 100% false-positive rate on the `design` route.
